## Featured projects

### Ardevane — guest website and staff dashboard

A cabin hotel system in two React applications on one Supabase database. Guests book and manage their stay on the website; staff run the hotel from the dashboard. A reservation, a check-in or a food order made on one side shows up on the other.

- **[ardevane-website](https://github.com/ahmedmoh14314-code/ardevane-website)** — Next.js 14 App Router. Server Components for reads, Server Actions for writes, Google and email sign-in with Supabase Auth and a session refreshed in middleware, an availability-aware date picker, and an optimistic cancel. Live at [ardevane.netlify.app](https://ardevane.netlify.app).
- **[ardevane-operations](https://github.com/ahmedmoh14314-code/ardevane-operations)** — React + Vite + TanStack Query. Search, filter and pagination driven by the URL, prefetched pages, optimistic updates with rollback, lazy-loaded routes, light and dark themes. Also holds the database migrations and the database tests.

### Atyaf Al Reem — a business platform in production

An Arabic, mobile-first customer site (Next.js 15) and an internal management system (Laravel + Filament) for a marble business in Riyadh, launched in May 2026 and maintained since. The source is private; the **[case study](https://github.com/ahmedmoh14314-code/atyaf-al-reem-case-study)** covers the React-to-Next.js migration, RTL with CSS logical properties, and deployment. Live at [atyafalreem.com](https://atyafalreem.com).
